# QA Checklists

This folder contains reusable checklists for testing activities that recur across releases, rather than one-off test cases.

Examples may include:

* Smoke-test checklist for a fresh build
* Regression checklist scoped to a specific module
* UI/UX consistency checks (spacing, contrast, breadcrumb placement)
* Form and validation checks
* Pre-release readiness checklist

Checklist items are written as specific, checkable questions rather than broad statements like "the feature works correctly," since items phrased that vaguely cannot be verified consistently by different testers.
